DRTK API
===================================

DRTK is a PyTorch library that provides functionality for differentiable rasterization.

The package includes the following modules:

* :doc:`transform`
* :doc:`rasterize`
* :doc:`render`
* :doc:`transparent_render`
* :doc:`pixel_grid_mesh`
* :doc:`interpolate`
* :doc:`filter2d`
* :doc:`edge_grad_estimator`
