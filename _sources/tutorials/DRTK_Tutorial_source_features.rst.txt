Transmittance in the original surface grid
==========================================

Give each point in an original surface grid a face ID and barycentric
coordinates. After deforming the mesh, several of those points can project
to the same camera pixel. They lie at different depths and have different
amounts of material in front of them.

:func:`drtk.source_feature_stencil` evaluates source transmittance for each
point and returns it in the original query order. Reshaping these values
produces a field in the original grid, including points on layers behind
other surfaces. That field can guide feature processing and carry gradients
back to the deformation and material opacity.

   :width: 100%

   The three marked points project to the same pixel. Their returned values

This example optimizes a fold and its opacity by comparing predicted and
target transmittance fields in the original grid. Camera renders alongside
the fields show which surfaces produce the occlusions.

From a grid point to source transmittance
-----------------------------------------

Let :math:`q` identify a point in the original grid, :math:`X_\theta(q)` its
position on the deformed mesh, and :math:`\pi_k` the projection into source
camera :math:`k`. Its projected location is

.. math::

   p_k(q)=\pi_k(X_\theta(q)).

Transmittance to the receiving surface is

.. math::

   T_k(q)=\prod_{f\prec q}\left(1-\alpha_f(p_k(q))\right).

The product contains fragments preceding the receiver in the renderer's
stable triangle-depth order. The receiver's own opacity is excluded. Thus a
front surface has transmittance one, while a point behind one layer of opacity
0.65 has transmittance 0.35. Behind two such layers, it is 0.1225.

For bilinear image sampling, the operator evaluates transmittance separately
at each of the four texel taps. Its returned confidence is

.. math::

   c_k(q)=\sum_{j=1}^{4}b_{qj}T_{kqj},

where :math:`b_{qj}` are the bilinear coefficients. Taps outside the image or
the receiving surface contribute zero. The confidence is therefore a
filtered transmittance value that also accounts for the sampling footprint.

Returning the field to the original grid
----------------------------------------

Keep the query face IDs and barycentrics attached to the same material
points while updating the mesh vertices. Here, :math:`H_0\times W_0` is the
original query grid, and the batch dimension contains the source cameras:

.. code-block:: python

   vertices = deform_mesh(parameters)
   v_source = project_to_source_cameras(vertices)
   indices, weights, _, _ = drtk.source_feature_stencil(
       v_source, faces, query_faces, query_barycentrics,
       image_height, image_width,
       vertex_opacity=material_opacity,
   )
   transmittance = weights.sum(-1).reshape(num_cameras, H0, W0)

The final reshape uses the original ordering of the queries. A query does
not move to another output cell when its projection moves across the camera
image. If topology changes, construct face IDs and barycentrics for the new
mesh while preserving the intended original-grid correspondence.

Differentiating the returned field
----------------------------------

For a fixed set of covering fragments, opacity has the derivative

.. math::

   \frac{\partial T}{\partial\alpha_i}
   =-\prod_{\substack{f\prec q\\f\ne i}}(1-\alpha_f).

This expression also defines the derivative when a factor is zero; it does
not require division by :math:`1-\alpha_i`. The example checks that its three
marked queries have opacity derivatives 0, -1, and -0.7 when a shared opacity
parameter controls all folds.

Geometry changes the projection of each query, the interpolated opacity,
and the occlusion boundaries. Smooth derivatives handle projection and
interpolation. The boundary-motion estimator supplies the coverage-change
term and is enabled by default. Both contributions reach the parameters
used to deform the mesh.

The fitting objective in this example is entirely in the original grid:

.. math::

   L(\theta,a)=\frac{1}{K H_0 W_0}
   \sum_{k,q}\left(c_k(q;\theta,\sigma(a))-c_k^*(q)\right)^2.

Here, :math:`\theta` controls the fold, :math:`\sigma(a)` is its material
opacity, and :math:`c^*` is a synthetic target field generated from the
target mesh. The target camera images are not used as a fitting loss.

.. code-block:: python

   loss = (transmittance - target_transmittance).square().mean()
   loss.backward()
   optimizer.step()

The video uses three source views and jointly updates one fold parameter
and one material-opacity parameter. Both runs start from the same values
and use the same optimizer. The final values and residual field error are
shown in the video; the boundary estimator improves the deformation fit,
while the opacity derivatives adjust the intermediate transmittance levels.

Using the field with image features
-----------------------------------

The same stencil also returns source image features to the original grid:

.. code-block:: python

   sampled, confidence = drtk.sample_feature_stencil(
       source_features, indices, weights
   )
   sampled = sampled.reshape(num_cameras, num_channels, H0, W0)
   confidence = confidence.reshape(num_cameras, 1, H0, W0)
   prediction = model(original_features, sampled, confidence)

``sampled`` already includes the transmittance weights. Confidence lets a
model distinguish an attenuated observation from an observed feature whose
value is zero. For a single source view, a simple blend with existing
features is ``sampled + (1 - confidence) * original_features``.

Features already mixed by transparency or by an image encoder remain mixed;
transmittance describes access to the source observation.

Run the example
---------------

Download :download:`source_features_demo.py <../_static/source_features_demo.py>`.
It requires a CUDA-enabled DRTK installation, Matplotlib, and FFmpeg.

.. code-block:: bash

   python source_features_demo.py --output ./source_features_demo

The output contains the video, original-grid illustration, optimization
snapshots, measurements, and saved fields. See
:doc:`../api_reference/source_features` for coordinate conventions, tensor
shapes, and gradient behavior.
